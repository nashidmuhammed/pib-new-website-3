# PIB India Web Redesign Project

Official prototype redesigns and explorations for the **Press Information Bureau (PIB)**, Government of India.

---

## 📌 Primary Concept Pages

### 1. `conceptA-DBIM.html` — DBIM 3.0 Standard Direction (Recommended)
* **Design Philosophy:** Developed strictly adhering to the **Digital Branding & Identity Manual 3.0 (DBIM 3.0)** and **GIGW 3.0 / WCAG 2.1 AA** guidelines.
* **Key Features:**
  - Standardized bilingual government header with the State Emblem of India, PIB emblem lockup, and national accessibility bar.
  - Dedicated accessibility tools: High Contrast toggle, Text Resizing (`A-` / `A` / `A+`), Screen Reader skip navigation, and multi-language support.
  - 50% face container mandate for leadership cards featuring **Union Minister Shri Ashwini Vaishnaw** and **Principal Director General (PrDG) Shri Dhirendra Ojha**.
  - Structured government newsroom, categorized cabinet decisions, fact-checking hub, and interactive regional Kendra selector.

### 2. `conceptB.html` — Editorial & Creative UI/UX Exploration
* **Design Philosophy:** A modern, stylish editorial concept designed with reference to the shared UI/UX design (Style 2).
* **Key Features:**
  - Modern typography and fluid layout breaking away from rigid tabular formats.
  - Bold headline presentation, minimalist whitespace balancing, and contemporary visual storytelling.
  - Dynamic interactive micro-interactions, responsive carousel cards, and sleek media feeds designed for international media standards.

### 3. `current-page.html` — Modernized Current Portal
* **Design Philosophy:** An updated, optimized, and refined version of the existing live PIB portal that preserves **100% of existing content and structure** while eliminating clunky and outdated elements.
* **Key Features:**
  - Replaces awkward vertical scroll traps and empty layout gaps with compact grid cards, horizontal carousels, and pagination.
  - Retains all live dispatches, government widgets, press releases, explainer thumbnails, and data without missing any content.
  - Streamlined CSS architecture that loads faster and adapts smoothly across desktop, tablet, and mobile displays.

## 🚀 How to View the Prototypes
Simply open any of the HTML files directly in your web browser:
```bash
open conceptA-DBIM.html      # Opens Concept A (DBIM 3.0)
open conceptB.html           # Opens Concept B (Modern Stylish)
open current-page.html       # Opens Refined Current Page
```
